Game facts in the hero

Under the title the hero shows three rows of identical chips: year, type, status and perspective, then genres, then platforms. Nothing says which row is which, so the genre "Platform" reads like a platform. Three ways to name the groups, each drawn for a short game, a game with gaps in its data, and a long platform list at phone width.

Current

Four kinds of fact in one row, then two unlabelled rows. Every value is the same chip.

A · Labelled rows

Every group gets a name in a fixed left column. Values stay chips and keep their catalogue links.

  • Nothing to decode, and a missing field simply drops its row.
  • Six rows instead of three: the rating moves down by about 70px.
  • A label column does not centre, so on a phone the block is left-aligned under a centred title.
Shipped

B · Fact line and labelled lists

Single facts (year, type, perspective) become one line of text with the status as a Badge. Only the two lists, genres and platforms, keep chips, each behind a label.

  • Same three rows as today.
  • A chip now always means a list you can browse.
  • The status takes colour only when it is unusual (Delisted, Cancelled, Early Access); Released stays plain text.

C · Fact tiles and captioned lists

Year, type, status and perspective become StatTiles, the same tiles as the counters on the right of the hero. Genres and platforms get a caption above.

  • Strongest hierarchy: the facts read as a spec sheet.
  • Tallest of the three, and the hero ends up with two groups of tiles side by side.
  • StatTile is not a link, so the year and type filters need an onClick or go away.

Building it

  • Only widgets/game/GameHero changes: the single chips list splits into facts and lists. A and B use Chip and Badge as they are; C adds StatTile.
  • The status-to-tone map (Delisted, Cancelled, Offline → negative; Alpha, Beta, Early Access → attention; Rumored → muted) lives in entities/game, because Badge takes no domain-named tones.
  • All facts stay in the server HTML. If 18 platforms is too long, collapse the row with ExpandableBlock clampHeight, never by slicing the list.
  • B shipped as entities/game/ui/GameFacts (also used by the Gauntlet winner) with one new token, --game-facts-label-width (84px) in _components.scss, which this mockup now reads too.

Colours, spacing and radii are the project's own tokens: the :root block above is generated from apps/web/src/lib/app/styles/vars by bun --filter web sync:tokens. The typeface is substituted — Hanken Grotesk stands in for ApercuPro, whose licensed file cannot be served from a third-party host.
